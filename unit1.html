1. History of the Internet

1.1 Introduction

The Internet is one of the most important technological developments in modern history. It is a worldwide system of interconnected computer networks that allows billions of devices to communicate and exchange information.

The Internet is often called a "network of networks" because it connects many different networks together. A school, college, company or government organization may have its own private network, but these networks can communicate with other networks through Internet technologies.

Today, the Internet is used for education, communication, entertainment, banking, shopping, business and many other activities. However, the Internet did not develop in a single day. It is the result of many years of research in computer networking and communication technologies.

1.2 Early Development of Computer Networks

During the 1960s, researchers started thinking about ways to connect computers located at different places. At that time, computers were large and expensive machines. Connecting computers would allow researchers to share information, software and computing resources.

One important idea behind the development of the Internet was packet switching. In packet switching, a large message is divided into smaller pieces called packets. These packets travel through the network and are reassembled at their destination.

Packet switching made computer communication more flexible and efficient than traditional communication methods. This concept became an important foundation for modern computer networks.

1.3 ARPANET

ARPANET was one of the earliest and most important computer networks in the development of the Internet. It was developed as a research network to connect computers at different institutions.

By the end of 1969, four host computers were connected to the initial ARPANET. Researchers could use the network to share computing resources and communicate across long distances.

As the network grew, researchers discovered that computer networking could be useful for many activities. Electronic mail eventually became one of the most popular applications of early computer networks.

1.4 Development of TCP/IP

As more networks were created, a major problem appeared: different networks needed a common method for communicating with each other. This problem led to the development of TCP/IP.

TCP/IP stands for Transmission Control Protocol / Internet Protocol. These protocols provide rules for sending, receiving, addressing and routing data across interconnected networks.

TCP helps organize data and ensures that data can be properly delivered and reassembled. IP helps identify devices and route packets toward their destination.

TCP/IP became a major foundation of the modern Internet because it allowed different types of networks to communicate using common standards.

1.5 Important Development Timeline

  • 1960s: Researchers began developing ideas for connecting computers and sharing information.
  • 1969: The initial ARPANET connected four host computers.
  • 1970s: Networking research expanded and TCP/IP protocols were developed.
  • 1980s: TCP/IP became widely adopted and more research and educational networks became connected.
  • 1989: Tim Berners-Lee proposed the World Wide Web.
  • 1990s: The Web helped make Internet information and services easier for the general public to access.
  • Today: The Internet supports billions of users and a huge variety of online services.

1.7 Advantages of the Internet

  • Global Communication: People can communicate with others located anywhere in the world.
  • Easy Access to Information: Students, researchers and professionals can access educational and technical information.
  • Online Services: Banking, shopping, education and many government services are available online.
  • Business Opportunities: Companies can sell products and provide services to customers globally.
  • Collaboration: People can work together remotely using online tools and communication services.

1.8 Disadvantages of the Internet

  • Security Risks: Users and organizations must protect their accounts and information.
  • Privacy Concerns: Personal information can be collected or misused if proper security is not followed.
  • Incorrect Information: Not all information available online is reliable or accurate.
  • Dependence on Technology: Many activities become difficult when Internet services are unavailable.

1.9 Applications of the Internet

  • Online education and digital classrooms
  • Email and instant communication
  • Online banking and digital payments
  • E-commerce and online shopping
  • Social networking and content sharing
  • Video meetings and remote work
  • Cloud storage and online software services

1.10 Real-Life Example

Suppose a student wants to check the college website. The student's computer connects to the Internet through a network service. The browser communicates with the college's web server, receives the required information and displays the website on the screen.

1.11 Important Exam Points

  • ARPANET was an important early computer network.
  • Packet switching is an important networking concept.
  • TCP/IP provides common rules for communication between networks.
  • The World Wide Web is a major service that runs on the Internet.

2. World Wide Web (WWW)

2.1 Introduction

The World Wide Web, commonly known as the Web or WWW, is a system of interconnected web pages and resources that can be accessed through the Internet.

The Web allows users to access information using web browsers. A web page can contain text, images, videos, links and other multimedia content.

The World Wide Web was proposed by Tim Berners-Lee in 1989. The development of the Web introduced important technologies such as HTML, HTTP and URLs, which are still fundamental parts of web technology today.

2.2 Internet and WWW are Different

Many people use the terms Internet and World Wide Web as if they mean the same thing. However, they are different.

The Internet is the global network infrastructure that connects computers and devices. The World Wide Web is a service that uses this network infrastructure to provide web pages and online information.

2.3 Main Components of the World Wide Web

  • Web Browser: Software used to access and display web pages.
  • Web Server: A system that stores and provides website files to users.
  • Web Page: A document that contains information and is displayed in a browser.
  • URL: A web address that identifies the location of a resource on the Web.
  • HTTP: A protocol used for communication between browsers and web servers.
  • HTML: A markup language used to structure web page content.

2.4 How the World Wide Web Works

When a user wants to open a website, the user enters a URL or clicks a link. The web browser identifies the required server and sends a request for the web page.

The web server receives the request, processes it and sends the required web page or resource back to the browser. The browser then interprets the received content and displays it to the user.

2.6 Hyperlinks

One of the most important features of the World Wide Web is the use of hyperlinks. A hyperlink allows users to move from one web page or resource to another.

For example, when you click the "Notes" option on your own WebLearn website, the browser opens the notes page. This is an example of a hyperlink connecting two web pages.

2.7 Applications of the World Wide Web

  • Education: Students can access online courses, notes and educational websites.
  • Business: Companies can provide product information and online services.
  • E-Commerce: Customers can view and order products through websites.
  • Government Services: Many government forms and information services are available through websites.
  • Entertainment: Websites provide videos, music, games and other digital content.

2.8 Advantages of WWW

  • Provides easy access to information from different sources.
  • Supports text, images, audio and video content.
  • Allows information to be shared globally.
  • Hyperlinks make navigation between pages easy.
  • Supports online education, business and communication.

2.9 Disadvantages of WWW

  • Some websites may provide incorrect information.
  • Users need an Internet connection to access web resources.
  • Websites can create privacy concerns if data is not protected.
  • Too much information can sometimes make it difficult to find reliable content.

2.10 Real-Life Example

Consider a student searching for university information. The student opens a browser and enters the university website address. The browser sends a request to the university's web server. The server sends the website files back, and the browser displays the university information.

2.11 Important Exam Points

  • WWW stands for World Wide Web.
  • The Web is a service that operates over the Internet.
  • Web pages are accessed using web browsers.
  • HTML, HTTP and URLs are important Web technologies.
  • Hyperlinks connect different web pages and resources.

3. HTML (HyperText Markup Language)

3.1 Introduction

HTML stands for HyperText Markup Language. It is the standard markup language used to create and organize the structure of web pages.

HTML tells the web browser what different parts of a web page represent. For example, HTML can identify a heading, paragraph, image, link, table or form.

HTML is not generally considered a programming language because its primary purpose is to describe and structure content rather than perform complex logical operations.

3.2 Meaning of the Term HTML

  • HyperText: Text that can contain links to other documents or web pages.
  • Markup: Tags are used to mark different parts of a document.
  • Language: HTML follows a standard set of rules for creating web documents.

3.3 Basic Structure of an HTML Document

<!DOCTYPE html>
<html>

<head>
    <title>My First Web Page</title>
</head>

<body>

    <h1>Welcome to My Website</h1>

    <p>
        This is a simple web page created using HTML.
    </p>

</body>

</html>

3.4 Explanation of the HTML Structure

<!DOCTYPE html> tells the browser that the document uses HTML5.

<html> is the root element of an HTML document. Most of the content of the page is placed inside this element.

<head> contains information about the document, such as the title and links to CSS files.

<title> defines the title displayed in the browser tab.

<body> contains the visible content that users see on the web page.

3.6 Common HTML Elements

  • <h1> to <h6> – Used for headings.
  • <p> – Used for paragraphs.
  • <a> – Used to create hyperlinks.
  • <img> – Used to display images.
  • <ul> and <ol> – Used to create lists.
  • <table> – Used to create tables.
  • <form> – Used to collect user information.

3.7 HTML Tags and Attributes

HTML uses tags to define elements. Some tags also use attributes to provide additional information. 

<a href="notes.html">Open Notes</a>

In the above example, <a> is the anchor tag and href is an attribute. The href attribute tells the browser where the link should open.

3.8 Applications of HTML

  • Creating the structure of websites.
  • Creating educational websites and online portals.
  • Creating forms for user input.
  • Displaying text, images and multimedia content.
  • Creating navigation between different web pages.

3.9 Advantages of HTML

  • Easy to Learn: HTML has a simple structure and is suitable for beginners.
  • Browser Support: Modern web browsers support HTML.
  • Free and Open: HTML can be used without purchasing special software.
  • Works with Other Technologies: HTML works together with CSS for styling and JavaScript for interactivity.
  • Supports Multimedia: HTML can be used to include images, audio and video content.

3.10 Limitations of HTML

  • HTML alone cannot create complex interactive behavior.
  • CSS is required for advanced page styling and layout.
  • JavaScript is required for many dynamic and interactive features.
  • HTML alone does not manage databases or server-side processing.

3.11 Real-Life Example

Your own WebLearn project is a good example of HTML usage. Files such as index.html, syllabus.html and notes.html use HTML to create the structure of different pages.

The navigation bar, headings, paragraphs, buttons and links are all created using HTML elements. CSS is then used to improve the appearance of these elements.

3.13 Important Exam Points

  • HTML stands for HyperText Markup Language.
  • HTML is used to structure web page content.
  • HTML uses tags and attributes.
  • The head contains document information.
  • The body contains the visible content of a web page.
  • HTML works with CSS and JavaScript to create modern websites.
