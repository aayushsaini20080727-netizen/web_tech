1. HTML Lists

1.1 Introduction

Lists are used to organize related information in a clear and structured manner. On a web page, information is often easier to understand when it is displayed as a list instead of a large paragraph.

Lists are commonly used for navigation menus, course topics, product features, instructions, steps and many other types of information. HTML provides three major types of lists: ordered lists, unordered lists and description lists.

1.2 Types of Lists

  • Ordered List: Used when the order of items is important.
  • Unordered List: Used when items do not require a specific order.
  • Description List: Used to display terms with their descriptions.

1.3 Ordered List

An ordered list is created using the <ol> tag. Each item inside the list is created using the <li> tag. Ordered lists are useful when information must be followed in a particular sequence. 

<ol>
    <li>Open the web browser</li>
    <li>Enter the website address</li>
    <li>Press Enter</li>
</ol>

1.4 Unordered List

An unordered list is created using the <ul> tag. It normally displays items using bullet points. The sequence of the items is not important in an unordered list. 

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

1.5 Description List

A description list is used when a term and its explanation need to be displayed together. The <dl> tag creates the list, <dt> defines the term and <dd> defines its description.

HTML Lists

│

├── Ordered List → <ol>

├── Unordered List → <ul>

└── Description List → <dl>

1.6 Advantages

  • Organizes information in a simple way.
  • Makes web content easier to read.
  • Useful for menus and navigation.
  • Can easily be designed using CSS.

1.7 Applications and Real-Life Example

Lists are used on educational websites to display subjects and unit topics. For example, the navigation bar of the WebLearn website contains different options such as Home, Syllabus and Notes. A course syllabus can also use lists to show topics in each unit.

Important Exam Points

  • <ol> creates an ordered list.
  • <ul> creates an unordered list.
  • <li> represents a list item.
  • <dl>, <dt> and <dd> are used for description lists.

2. HTML Tables

2.1 Introduction

Tables are used to display structured information in the form of rows and columns. They are useful when different values need to be compared or when information naturally belongs in a tabular format.

Examples of information commonly displayed in tables include student marks, timetables, product information, financial data and course details.

2.2 Main Table Tags

  • <table> – Creates the complete table.
  • <tr> – Creates a table row.
  • <th> – Creates a heading cell.
  • <td> – Creates a data cell.

2.3 Example

<table>

    <tr>
        <th>Subject</th>
        <th>Marks</th>
    </tr>

    <tr>
        <td>Web Technology</td>
        <td>85</td>
    </tr>

</table>

2.4 Table Diagram

<table>

│

├── <tr> → Table Row

│    ├── <th> → Heading

│    └── <th> → Heading

│

└── <tr> → Table Row

     ├── <td> → Data

     └── <td> → Data

2.5 Advantages and Applications

Tables organize large amounts of structured information and make comparison easier. They are widely used for timetables, mark sheets, product comparisons and reports.

2.6 Limitations

  • Large tables may be difficult to read on mobile devices.
  • Complex tables can confuse users.
  • Tables should mainly be used for data, not complete page layouts.

Real-Life Example

A university website can use a table to display a student's examination marks. Each row represents a subject and different columns can represent marks, grades and results.

3. Images in HTML

3.1 Introduction

Images make web pages more attractive and help users understand information visually. Websites use images for logos, product photographs, diagrams, icons and educational content.

The <img> tag is used to display an image in HTML. The browser uses the image source to find and display the required image file.

3.2 Basic Syntax

<img src="college.jpg"
     alt="College Building">

3.3 Important Attributes

  • src: Specifies the location of the image.
  • alt: Provides alternative text.
  • width: Specifies image width.
  • height: Specifies image height.

3.4 Advantages

  • Makes websites visually attractive.
  • Helps explain difficult concepts.
  • Improves user engagement.
  • Useful for branding and identification.

3.5 Disadvantages

  • Large images can slow down a website.
  • Too many images can increase page loading time.
  • Poor-quality images can reduce the quality of a website.

Real-Life Example

A college website can display images of the campus, laboratories and classrooms. In educational notes, diagrams and images help students understand technical topics more easily.

4. HTML Forms

4.1 Introduction

Forms are used to collect information from users. They are an important part of interactive websites because they allow users to enter data and send that data for processing.

Login pages, registration pages, feedback forms and online application forms are common examples of HTML forms.

4.2 Common Form Elements

  • <form> – Creates a form.
  • <input> – Accepts user input.
  • <label> – Provides a description for an input field.
  • <textarea> – Accepts multi-line text.
  • <select> – Creates a drop-down menu.
  • <button> – Creates a clickable button.

4.3 Form Working

4.4 Example

<form>

    <label>Name:</label>
    <input type="text">

    <br><br>

    <label>Email:</label>
    <input type="email">

    <br><br>

    <button type="submit">
        Submit
    </button>

</form>

Applications

  • User registration
  • Login systems
  • Feedback forms
  • College admission forms
  • Online shopping

Real-Life Example

Your WebLearn website can use a feedback form where students enter their name, email and feedback. The information can then be processed and stored by the website.

5. Frames

5.1 Introduction

Frames were historically used to divide a browser window into multiple sections. Each section could display a different HTML document. For example, one frame could contain navigation while another frame displayed the main content.

Traditional HTML frames are now considered outdated in modern web development. Modern websites generally use CSS layouts and other technologies instead.

5.2 Conceptual Diagram

+----------------------------------+

| Header Frame |

+--------------+-------------------+

| Navigation | Main Content |

| Frame | Frame |

+--------------+-------------------+

5.3 Advantages

  • Allowed different documents to appear in one window.
  • Navigation could remain visible while content changed.
  • Provided an early method for dividing page layouts.

5.4 Disadvantages

  • Can create navigation and usability problems.
  • Not suitable for many modern responsive websites.
  • Traditional frame-based layouts are obsolete in modern HTML.

Modern Alternative

Modern web development uses CSS Flexbox, CSS Grid and other layout technologies to create responsive sections of a website. The <iframe> element may still be used to embed another document or external content in a web page.

6. Dynamic HTML (DHTML) with JavaScript

6.1 Introduction

Dynamic HTML refers to techniques that allow a web page to change after it has been loaded in the browser. It generally involves the combined use of HTML, CSS and JavaScript.

HTML provides the structure of a page, CSS controls its appearance and JavaScript adds behavior and interactivity. Together, these technologies can create dynamic web pages.

6.2 JavaScript

JavaScript is a programming language commonly used to add interactive features to websites. It can respond to user actions such as clicking buttons, entering text or moving the mouse.

6.3 Simple Example

<button onclick="changeText()">
    Click Me
</button>

<p id="message">
    Welcome to WebLearn
</p>

<script>

function changeText() {
    document.getElementById("message").innerHTML =
    "Text Changed Successfully!";
}

</script>

6.5 Applications

  • Interactive buttons
  • Form validation
  • Image galleries
  • Dynamic menus
  • Online calculators

Advantages

  • Creates interactive websites.
  • Improves user experience.
  • Can update page content without completely changing the page.

Real-Life Example

When a user clicks a button on a website and a menu opens immediately without loading another page, JavaScript is often responsible for that interaction.

7. Cascading Style Sheets (CSS)

7.1 Introduction

CSS stands for Cascading Style Sheets. It is used to control the appearance and presentation of HTML documents.

CSS can control colors, fonts, spacing, borders, layouts and responsive design. Separating HTML structure from CSS design makes websites easier to manage and maintain.

7.2 Types of CSS

  • Inline CSS: Written directly inside an HTML element.
  • Internal CSS: Written inside a <style> tag.
  • External CSS: Written in a separate CSS file.

7.3 CSS Example

h1 {
    color: blue;
    text-align: center;
}

p {
    font-size: 18px;
}

7.5 Advantages of CSS

  • Separates content from design.
  • Provides a consistent website design.
  • Reduces repeated formatting code.
  • Supports responsive web design.

7.6 Applications

CSS is used on almost every modern website. Your WebLearn project uses the same style.css file to provide a consistent design for the Home, Syllabus and Notes pages.

8. Document Type Definition (DTD)

8.1 Introduction

DTD stands for Document Type Definition. It is used to define the legal structure and elements of an XML document.

A DTD can specify which elements are allowed, how elements are organized and what type of structure an XML document should follow.

8.2 Example

<!ELEMENT student (name, course)>
<!ELEMENT name (#PCDATA)>
<!ELEMENT course (#PCDATA)>

8.3 Advantages

  • Defines a standard structure for XML documents.
  • Helps validate XML data.
  • Allows multiple documents to follow the same format.

8.4 Limitations

  • Provides fewer data type options than XML Schema.
  • Can be less flexible for complex data.

Real-Life Example

An organization can use a common document definition to ensure that all student information XML files follow the same structure.

9. XML Schema

9.1 Introduction

XML Schema is a technology used to define the structure, elements and data types of an XML document. It provides more detailed validation features than traditional DTD.

XML Schema can specify whether a value should contain text, numbers, dates or other types of information. It helps ensure that XML data follows required rules.

  • Supports different data types.
  • Provides detailed validation.
  • Useful for complex XML documents.

Application

XML Schema is useful when organizations exchange structured information and need to ensure that the data follows a defined format.

10. Object Models

10.1 Introduction

An object model represents a document or application as a collection of objects. In web development, the most commonly discussed object model is the Document Object Model, also known as DOM.

The DOM represents an HTML or XML document as a tree of objects. JavaScript can access and modify these objects to create dynamic web pages.

10.2 DOM Tree

10.3 Application

JavaScript can use the DOM to change text, update styles, create new elements or respond to user actions.

Real-Life Example

When a user clicks a button and the text on a page changes, JavaScript accesses the required HTML element through the DOM and modifies its content.

11. Presenting XML

11.1 Introduction

XML is mainly designed to store and transport structured data. However, raw XML data is not always easy for users to read. Therefore, XML data may need to be transformed or styled before it is presented to users.

Technologies such as CSS and XSLT can be used to present XML information in a readable format.

12. XML Processors – DOM and SAX

12.1 Introduction

XML processors are software components that read and process XML documents. Different processing approaches are available, including DOM and SAX.

12.2 DOM Parser

A DOM parser reads the complete XML document and creates a tree-like structure in memory. This allows a program to move through the document and access different nodes.

↓

↓

12.3 SAX Parser

SAX stands for Simple API for XML. A SAX parser processes an XML document sequentially and generates events while reading the document.

Unlike a DOM parser, SAX does not normally create a complete tree of the entire document in memory. Therefore, it can be useful when processing large XML documents.

XML Document

↓

↓

12.4 Difference Between DOM and SAX

  • DOM: Creates a complete tree structure.
  • SAX: Processes XML sequentially.
  • DOM: Easier to navigate and modify documents.
  • SAX: Can use less memory for large documents.

Applications

XML processors are used when applications need to read, validate or extract information from XML documents. They can be useful in data exchange systems and software applications that work with structured XML data.

Important Exam Points

  • DOM represents XML as a tree structure.
  • SAX processes XML sequentially using events.
  • DOM is useful for navigation and modification.
  • SAX can be useful for processing large documents.

Unit 2 Summary

Unit 2 introduces important technologies used in web page development. HTML elements such as lists, tables, images and forms are used to organize and display web content. CSS is used to improve the appearance of web pages, while JavaScript adds interactivity and dynamic behavior.

The unit also introduces XML and related technologies. DTD and XML Schema define and validate XML structure. The DOM represents documents as objects, while XML processors such as DOM and SAX provide different methods for reading and processing XML data.
